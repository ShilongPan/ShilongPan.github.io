This is my first Jekyll-powered blog post. The content is written in Markdown, and the layout is handled by Jekyll's templating system.

## What Changed

Previously, each blog post was a full HTML file that I had to manually link from the blog index page. Now:

- Write content in **Markdown** (no HTML needed)
- Add a YAML front-matter block with title, date, and categories
- Jekyll automatically generates the HTML, the blog index, and permalinks
- Everything is version-controlled in Git

## Why This Matters

It means adding a new post is as simple as:

1. Creating a file named `YYYY-MM-DD-title.md` in `_posts/`
2. Writing your content
3. Committing and pushing

That's it. No more copying nav bars, no more updating the blog index manually.
